{% comment %} Google Analytics event tracking, wired by watching clicks and form submits page-wide so individual templates don't need tracking code. Events go through window.ppTrack (layouts/blank.html), which does nothing unless GA_MEASUREMENT_ID is set and the visitor accepted analytics cookies. Only event names and coarse labels are sent — never search text, locations, names, or prescription details. Two events fire from their own templates because they only happen after a fetch() succeeds: submit_review (partials/review-modal.html) and add_to_compare (pages/list.html). {% endcomment %}
